# 平台能力支持矩阵

> 本文档记录各平台对 AME to do 能力的支持状态。新增平台时请先更新此文档，再进入实现阶段。

## 状态说明

| 状态 | 含义 |
|---|---|
| ✅ 已支持 | 该平台已完整实现此能力 |
| ⏳ 待实现 | 计划支持，但尚未开始实现 |
| 🔍 调研中 | 正在评估该平台是否支持此能力及实现方案 |
| ❌ 不支持 | 该平台原生不支持或成本过高，暂不实现 |
| 🚧 部分支持 | 已实现核心能力，但部分细节待完善 |

## 新增平台 Checklist

新增平台（例如鸿蒙）时，请按以下顺序推进：

1. [ ] 在 `apps/` 下新增平台入口目录
2. [ ] 在 `packages/platform-implementations/` 下新增平台实现目录
3. [ ] 更新本文档，将所有能力标记为对应状态
4. [ ] 按能力优先级逐步实现：文件系统 → 数据存储 → 通知 → 网络 → 其他
5. [ ] 每实现一项能力，更新本文档对应单元格状态
6. [ ] 更新 `docs/PORTING_GUIDE.md`，记录该平台的特有注意事项
